# グラブル便利ツール

グランブルーファンタジーの**素材集め**と**ガチャの天井**を管理する、ブラウザだけで動くツールです。
サーバーやインストールは不要で、ブラウザで開くだけで使えます。

## 機能

### 素材トラッカー
- 目標（例: 十天衆の最終上限解放）ごとに、必要な素材と数を管理する
- 所持数を入れると、不足数と、素材がそろった目標がひと目でわかる
- 「1周あたりの平均ドロップ数」を入れると、あと何周必要かの目安を出す
- 目標を完了すると、使った素材を所持数から自動で差し引く（元に戻すこともできる）
- プリセットから選ぶだけで、必要素材を自動で入力できる

### バックアップ
- データをJSONファイルに書き出す／読み込む（ページの一番下）

### 天井計算（別ツール）
`spark/` フォルダにある、素材トラッカーとは独立したページです。HTML・CSS・JavaScript もデータの保存先も別なので、フォルダごと取り出しても動きます。
- 宝晶石、単発・10連チケット、ガチャPtから、今何連分あるかを計算する
- 天井（300連）何回分か、次の天井まであと何連・宝晶石何個かを出す
- ガチャチケットを宝晶石に換算した数も出す

## 使い方
- GitHub Pages で公開しているページを開く
- または、このリポジトリをダウンロードして（Code → Download ZIP、または `git clone`）、`index.html` をブラウザで開く

データはブラウザのlocalStorageに保存され、サーバーには送られません。ブラウザのデータを消すと消えるので、ときどき「バックアップ」から書き出してください。素材のアイコン画像も、登録した人のブラウザの中にだけ保存されます。

## 収録プリセット
| コンテンツ | 内容 |
|---|---|
| 十天衆 | 最終上限解放（銀の依代・依代6種・黄金の依代・最終）、限界超越 Lv110〜150 |
| 天星器（十天衆加入） | 変更先の属性ごとに第1〜9段階（設備拡充を含む） |
| 十賢者 | アーカルム召喚石の交換〜5凸、加入、至賢の領域、礎武器の交換〜5凸、最終上限解放、4アビ、限界超越 Lv110（マリア・テレサ、カイム） |
| 天司武器 / エニアド / 六竜武器 | 4凸 |
| レヴァンスウェポン | 4凸、覚醒Lv、特殊強化 |
| 終末武器 | 交換〜5凸、限界超越 Lv210〜250 |
| ドラゴニックウェポン | 交換〜特殊強化 |

それぞれ「全段階まとめて」も用意しています。

- 出典は主に [GameWith](https://xn--bck3aza1a2if6kra4ee0hf.gamewith.jp/) の各記事です（各プリセットの「出典」リンクから確認できます）
- ゲームのアップデートで必要数が変わることがあります。実際の数はゲーム内で確認してください

## ファイル構成
```
index.html      # 素材トラッカー
css/style.css
js/
├─ storage.js   # localStorage への保存と読み込み
├─ util.js      # DOM 生成ヘルパーなど
├─ icons.js     # 素材のアイコン画像
├─ presets.js   # 目標プリセット（必要素材データ）
├─ sources.js   # 素材の入手先
├─ tracker.js   # 素材トラッカー
├─ app.js       # データの保持、昼／夜の切り替え
└─ backup.js    # バックアップ
spark/          # 天井計算（独立したツール）
├─ index.html
├─ style.css
└─ spark.js
```
ES Modulesは使わず、普通のscriptタグで読み込んでいます（ファイルを直接開いても動くようにするため）。
