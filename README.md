# グラブル便利ツール

バックエンドなしで動く、グラブル用の素材トラッカーと天井計算ツール。`index.html` をブラウザで開くだけで使える。データはブラウザの localStorage に保存される（バックアップタブから JSON で書き出し／読み込みができる）。

## 構成
- `js/storage.js` … localStorage への保存と読み込み
- `js/util.js` … DOM 生成ヘルパーなど
- `js/presets.js` … 目標プリセット（必要素材データ）
- `js/tracker.js` … 素材トラッカー
- `js/spark.js` … 天井（300連）計算
- `js/app.js` … タブ切り替え、バックアップ、起動処理

ES Modules は使わず、普通の script タグで読み込んでいる（`file://` で開いても動くようにするため）。

## プリセットのデータ
- 十天衆 最終上限解放（10人 × 3段階 ＋ 依代6種の作成）
- 出典: GameWith（2026-09-29 取得）。URL は `js/presets.js` に記載
- 輝き、プシュケー、共闘素材の書、下位宝珠、ジーン、対応した武器エレメントは正式名称を確認できていないため、仮の名前にしている
