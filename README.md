# グラブル便利ツール

グランブルーファンタジーの**素材集め**を管理する、ブラウザだけで動くツールです。
サーバーやインストールは不要で、ブラウザで開くだけで使えます。

## 機能

### 目標と素材の管理
- 目標（例: 十天衆の最終上限解放）ごとに、必要な素材と数を管理する
- プリセットから選ぶだけで、必要な素材と数が自動で入る。プリセットにないものは、自分で素材を指定して目標を作れる
- 所持数を入れると、目標ごとの不足数と、素材がそろった目標がひと目でわかる
- ほかの目標でも使う素材には「共通」の印が付く。「全素材の合計」で、すべての目標の不足をまとめて確認できる
- 「1周あたりの平均ドロップ数」を入れると、あと何周必要かの目安を出す
- 目標を完了すると、使った素材を所持数から自動で差し引く（元に戻すこともできる）。目標の複製もできる

### 見やすさ
- 目標リストは「キャラ／武器／その他」に分かれ、目標ごとに折りたためる（すべて開く／閉じるもできる）
- 素材名の下に、主な入手先を表示する
- 素材のアイコン画像を自分で登録できる（画像は登録した人のブラウザの中にだけ保存される）
- 昼／夜の配色を切り替えられる（既定は夜）

### バックアップ
- データをJSONファイルに書き出す／読み込む（ページの一番下）

## 使い方
1. このリポジトリをダウンロードする（Code → Download ZIP、または `git clone`）
2. `index.html` をブラウザで開く

データはブラウザのlocalStorageに保存され、サーバーには送られません。ブラウザのデータを消すと消えるので、ときどき「バックアップ」から書き出してください。

## 収録プリセット
全636件です。コンテンツは「キャラ」と「武器」に分かれていて、十天衆・十賢者はキャラ名から、武器は武器名から選びます。

| 分類 | コンテンツ | 内容 |
|---|---|---|
| キャラ | 十天衆 | 最終上限解放（銀の依代・依代6種・黄金の依代・最終）、限界超越 Lv110〜150 |
| キャラ | 天星器（十天衆加入） | 変更先の属性ごとに第1〜9段階（第3段階の設備拡充は初回のみ） |
| キャラ | 十賢者（10人） | アーカルム召喚石の交換〜5凸、加入、至賢の領域、礎武器の交換〜5凸、最終上限解放、4アビ。限界超越 Lv110 はマリア・テレサとカイムのみ |
| 武器 | 天司武器 / エニアド / 六竜武器 | 4凸 |
| 武器 | レヴァンスウェポン | 4凸、覚醒Lv1→15、特殊強化（リビルド）、覚醒Lv15→20 |
| 武器 | 終末武器 | 交換、4凸、第2スキル付与、5凸、第3スキル付与、限界超越 Lv210〜250 |
| 武器 | ドラゴニックウェポン | 交換、4凸、5凸、特殊強化 |

段階が複数あるものには「全段階まとめて」も用意しています。

- プリセットの出典は [GameWith](https://xn--bck3aza1a2if6kra4ee0hf.gamewith.jp/) の各記事です（各プリセットの「出典」リンクから確認できます）。素材の入手先は、GameWith と神ゲー攻略を参考にしています
- ゲームのアップデートで必要数が変わることがあります。実際の数はゲーム内で確認してください
- 正式名称を確認できていない素材は、仮の名前にしています（終末武器の「恩寵（属性）」（風以外）と「新恩寵（属性）」、光・闇の Lv240 の「光輪」）

## ファイル構成
```
index.html
css/style.css
js/
├─ storage.js   # localStorage への保存と読み込み
├─ util.js      # DOM 生成ヘルパーなど
├─ icons.js     # 素材のアイコン画像
├─ presets.js   # 目標プリセット（必要素材データ）
├─ sources.js   # 素材の入手先
├─ tracker.js   # 素材トラッカー
├─ app.js       # データの保持、昼／夜の切り替え
└─ backup.js    # バックアップ
```
ES Modulesは使わず、普通のscriptタグで読み込んでいます（ファイルを直接開いても動くようにするため）。
