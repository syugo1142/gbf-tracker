# グラブル便利ツール

グランブルーファンタジーの上限解放などに必要な素材の数を管理するツールです。ブラウザで開いて使います。

## 機能
- 目標（例: 十天衆の最終上限解放）ごとに、必要な素材と数を登録する。プリセットから選ぶか、素材を自分で指定する
- 素材の所持数を入力すると、目標ごとの不足数を表示する
- 複数の目標で使う素材には「共通」と表示する。「全素材の合計」で、全目標の不足数をまとめて表示する
- 1周あたりの平均ドロップ数を入力すると、必要な周回数の目安を表示する
- 目標を完了すると、使った素材を所持数から差し引く（取り消し可）。目標の複製もできる
- 目標は「キャラ／武器／その他」に分けて表示する
- 素材名の下に、主な入手先（例: 朱緋の試練、六竜の試練）を表示する
- 素材のアイコン画像を登録できる。画像はブラウザ内にだけ保存する
- データをJSONファイルに書き出し・読み込みできる（ページ下部の「バックアップ」）

## 使い方
https://syugo1142.github.io/gbf-tracker/ を開きます。

データはブラウザのlocalStorageに保存し、サーバーには送りません。ブラウザのデータを消すと消えるので、「バックアップ」から書き出しておいてください。

## 収録プリセット
全636件です。

| 分類 | 対象 | 内容 |
|---|---|---|
| キャラ | 十天衆 | 最終上限解放（銀の依代・依代6種・黄金の依代・最終）、限界超越 Lv110〜150 |
| キャラ | 天星器（十天衆加入） | 属性ごとに第1〜9段階（第3段階の設備拡充は初回のみ） |
| キャラ | 十賢者 | アーカルム召喚石の交換〜5凸、加入、至賢の領域、礎武器の交換〜5凸、最終上限解放、4アビ。限界超越 Lv110 はマリア・テレサとカイムのみ |
| 武器 | 天司武器 / エニアド / 六竜武器 | 4凸 |
| 武器 | レヴァンスウェポン | 4凸、覚醒Lv1→15、特殊強化（リビルド）、覚醒Lv15→20 |
| 武器 | 終末武器 | 交換、4凸、第2スキル付与、5凸、第3スキル付与、限界超越 Lv210〜250 |
| 武器 | ドラゴニックウェポン | 交換、4凸、5凸、特殊強化 |

段階が複数あるものには「全段階まとめて」もあります。

- 必要数の出典は [GameWith](https://xn--bck3aza1a2if6kra4ee0hf.gamewith.jp/) の各記事です（各プリセットの「出典」リンク）。入手先は GameWith と神ゲー攻略を参考にしています
- アップデートで必要数が変わることがあります。実際の数はゲーム内で確認してください
- 次の素材は正式名称を確認できていないため、仮の名前です: 終末武器の「恩寵（属性）」（風以外）と「新恩寵（属性）」、光・闇の Lv240 の「光輪」

## 開発
画面は [Vite](https://vite.dev/) でビルドしています。Node.js 24 以降が必要です。
```
npm ci            # 開発用の道具（Vite、TypeScript など）を入れる
npm run dev       # 開発用サーバーを起動する（http://localhost:5173/）
npm run build     # 公開用のファイルを dist/ に作る
npm run preview   # ビルドしたものを手元で確かめる
npm start         # 同期サーバーを起動する（作成中。http://localhost:3000/api/hello）
npm run typecheck # 型の間違いがないか確かめる
```
main に push すると、GitHub Actions がビルドして GitHub Pages に公開します。

## ファイル構成
```
index.html
src/
├─ main.js      # 画面の入口（各ファイルを読み込んで起動する）
├─ style.css    # 見た目
├─ storage.ts   # localStorage への保存と読み込み、保存データの型
├─ util.ts      # DOM 生成ヘルパーなど
├─ icons.js     # 素材のアイコン画像
├─ presets.js   # 目標プリセット（必要素材データ）
├─ sources.js   # 素材の入手先
├─ tracker.js   # 素材トラッカー
├─ app.ts       # データの保持
├─ backup.js    # バックアップ
└─ tsconfig.json # 画面用の TypeScript の設定（ブラウザ向け）
server/
└─ server.ts    # 端末間の同期機能（作成中。公開ページでは使っていない）
package.json    # コマンドの一覧と、開発用の道具
vite.config.ts  # Vite の設定
tsconfig.json   # TypeScript の型チェックの設定（サーバー・Vite の設定ファイル向け）
.github/workflows/
├─ deploy.yml    # push のたびにビルドして GitHub Pages に公開する
└─ typecheck.yml # push のたびに型チェックを実行する
```
